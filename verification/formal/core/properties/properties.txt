Proofs
------

Reset
P1. Reset initializes every thread's fetch, sleep, response, and LSU state.

Instruction interface
P2. Instruction requests are aligned, legal, and always accept page messages.
P3. Accepted fetches become pending for the selected thread.
P4. Fetch request payload remains stable under backpressure.

Data interface
P5. Data requests identify a legal thread and reads have no write strobes.
P6. Accepted LSU requests become pending until completion.
P7. LSU request payload remains stable under backpressure.

Page-message interface
P8. Outbound page messages remain stable under backpressure.

Cover
-----

C1. Cover an accepted fetch and instruction response.
C2. Cover an accepted data request.
C3. Cover an outbound page message under backpressure.
