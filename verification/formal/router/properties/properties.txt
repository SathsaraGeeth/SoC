Proofs
------

Reset
P1. Reset clears all externally visible and directional response buffers.

Requests
P2. Instruction requests select exactly the decoded direction and preserve payload.
P3. Data requests select either one memory direction or MMIO and preserve payload.

Page messages
P4. Core page messages use the local East direction for the verified coordinates.
P5. Incoming instruction/data page messages use fixed W/S/E/N priority.

Responses
P6. Instruction, data, and page-message responses remain stable under backpressure.

Cover
-----

C1. Cover North and West instruction routes.
C2. Cover MMIO data routing.
C3. Cover instruction, data, and page-message response backpressure.
