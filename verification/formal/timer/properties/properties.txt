Proofs
------

P1. Reset restores MTIME, MTIMECMP, and response state.
P2. MTIME increments exactly once per active clock.
P3. The timer interrupt equals MTIME >= MTIMECMP.
P4. Request readiness is determined by response capacity.
P5. A stalled response remains valid with stable data.
P6. Every accepted request produces a response.

Cover
-----

C1. Read and write requests are accepted.
C2. A response can be backpressured.
C3. The timer interrupt is reachable.
